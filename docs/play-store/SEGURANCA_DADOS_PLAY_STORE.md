# 🔒 Segurança dos Dados - Play Store

Guia para preencher a seção "Segurança dos dados" no Play Console.

---

## 📋 Pergunta Principal

**"O app coleta ou compartilha algum dos tipos de dados do usuário obrigatórios?"**

---

## ✅ Resposta para FinFlow

### **Resposta: SIM**

O FinFlow coleta dados do usuário, então você deve responder **"Sim"**.

---

## 📊 Tipos de Dados que o FinFlow Coleta

### **1. Dados Financeiros** ✅
- **O que:** Receitas, despesas, contas bancárias, saldos
- **Finalidade:** Funcionalidade do app (gerenciar finanças)
- **Coletado de:** Dados inseridos pelo usuário
- **Compartilhado:** ❌ NÃO

### **2. Dados de Conta** ✅
- **O que:** Email, nome, telefone (opcional)
- **Finalidade:** Autenticação e comunicação
- **Coletado de:** Dados fornecidos pelo usuário
- **Compartilhado:** ❌ NÃO

### **3. Dados de Uso** (Opcional)
- **O que:** Informações sobre como o app é usado
- **Finalidade:** Melhorar o app
- **Coletado de:** Uso do aplicativo
- **Compartilhado:** ❌ NÃO

---

## 📝 Como Preencher no Play Console

### **Etapa 1: Responder a Pergunta**

**"O app coleta ou compartilha algum dos tipos de dados do usuário obrigatórios?"**

**Resposta:** ✅ **SIM**

---

### **Etapa 2: Declarar Tipos de Dados**

Após responder "Sim", você precisará declarar:

#### **Categoria: Dados Financeiros**

**Tipo:** Informações financeiras
- ✅ **Coletado:** Sim
- **Finalidade:** Funcionalidade do app
- **Coletado de:** Dados inseridos pelo usuário
- **Compartilhado:** Não
- **Dados sensíveis:** Sim (dados financeiros pessoais)

#### **Categoria: Dados de Conta**

**Tipo:** Informações de conta
- ✅ **Coletado:** Sim
- **Finalidade:** Autenticação
- **Coletado de:** Dados fornecidos pelo usuário
- **Compartilhado:** Não
- **Dados sensíveis:** Não (email, nome)

#### **Categoria: Dados de Contato** (Opcional)

**Tipo:** Telefone (se coletado)
- ✅ **Coletado:** Sim (opcional)
- **Finalidade:** Notificações WhatsApp
- **Coletado de:** Dados fornecidos pelo usuário
- **Compartilhado:** Não
- **Dados sensíveis:** Não

---

## 🔒 Declarações de Segurança

### **1. Criptografia de Dados**

**Pergunta:** "Os dados são criptografados em trânsito?"

**Resposta:** ✅ **SIM**
- O app usa HTTPS para todas as comunicações
- Dados são transmitidos de forma segura

**Pergunta:** "Os dados são criptografados em repouso?"

**Resposta:** ✅ **SIM**
- Dados são armazenados de forma segura no servidor
- Banco de dados com criptografia

---

### **2. Compartilhamento de Dados**

**Pergunta:** "Os dados são compartilhados com terceiros?"

**Resposta:** ❌ **NÃO**
- FinFlow não compartilha dados com terceiros
- Dados são privados do usuário

---

### **3. Direitos do Usuário**

**Pergunta:** "Usuários podem solicitar exclusão de dados?"

**Resposta:** ✅ **SIM**
- Usuários podem excluir sua conta
- Dados podem ser removidos

## 📝 Texto Sugerido para Declarações

### **Dados Financeiros:**
```
O FinFlow coleta informações financeiras (receitas, despesas, contas) 
que o usuário insere no aplicativo. Esses dados são usados exclusivamente 
para fornecer a funcionalidade de gestão financeira pessoal. Os dados 
não são compartilhados com terceiros e são armazenados de forma segura 
e criptografada.
```

### **Dados de Conta:**
```
O FinFlow coleta informações de conta (email, nome, telefone opcional) 
para autenticação e comunicação. Esses dados são usados apenas para 
permitir o acesso ao app e enviar notificações (se configurado pelo 
usuário). Os dados não são compartilhados com terceiros.
```
