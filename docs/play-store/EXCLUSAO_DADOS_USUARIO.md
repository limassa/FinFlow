# 🗑️ Exclusão de Dados do Usuário - Play Store

Guia para responder sobre exclusão de dados sem excluir a conta.

---

## 📋 Pergunta do Play Console

**"Você oferece aos usuários uma maneira de solicitar que alguns ou todos os dados sejam excluídos, sem exigir a exclusão da conta?"**

---

## ✅ Resposta para FinFlow

### **Resposta: NÃO**

O FinFlow não oferece uma funcionalidade dedicada para solicitar exclusão de dados sem excluir a conta.

**Mas:**
- ✅ Usuários podem excluir dados individuais (receitas, despesas, contas) através das funcionalidades normais do app
- ✅ Usuários podem excluir a conta completa (que exclui todos os dados)

---

## 🔍 Funcionalidades Atuais do FinFlow

### **1. Exclusão de Dados Individuais** ✅

Os usuários podem excluir:

- ✅ **Receitas individuais** - Através da tela de Receitas
- ✅ **Despesas individuais** - Através da tela de Despesas
- ✅ **Contas bancárias individuais** - Através da tela de Contas

**Como funciona:**
- Usuário acessa o item (receita, despesa, conta)
- Clica em "Excluir"
- Confirma a exclusão
- O item é removido

### **2. Exclusão de Conta Completa** ✅

- ✅ Usuário pode excluir a conta completa
- ✅ Isso exclui todos os dados associados
- ✅ Disponível na tela de Configurações (web)

---

## ❌ O que NÃO existe

- ❌ Funcionalidade dedicada de "Solicitar exclusão de dados"
- ❌ Opção para excluir "todos os dados" sem excluir a conta
- ❌ Exclusão automática de dados após 90 dias

---

## 📝 Resposta Recomendada

**No Play Console, selecione:**

```
☑ Não
```

**Justificativa:**
- O app não oferece uma funcionalidade específica para solicitar exclusão de dados sem excluir a conta
- Usuários podem excluir dados individuais, mas isso é parte da funcionalidade normal do app
- Para excluir todos os dados, o usuário precisa excluir a conta

---

## 💡 Alternativa (Futuro)

Se você quiser implementar essa funcionalidade no futuro, poderia adicionar:

1. **Tela de "Gerenciar Dados"** nas Configurações
2. **Opções para excluir:**
   - Todas as receitas
   - Todas as despesas
   - Todas as contas
   - Dados de perfil (exceto email)
3. **Manter a conta ativa** após a exclusão
