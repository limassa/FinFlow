# 📋 Como Preencher Classificações de Conteúdo - FinFlow

Guia específico para preencher o questionário de Classificações de Conteúdo do Google Play Console.

---

## 🎯 Respostas para o App FinFlow

### **1. Aplicação transferida**

**Pergunta:**
```
A aplicação contém quaisquer conteúdos com classificação relevante 
(por exemplo, sexo, violência, linguagem) transferidos como parte 
do pacote de aplicações (código, ativos)?
```

**Resposta para FinFlow:**
```
❌ NÃO
```

**Motivo:**
- O FinFlow é um app de controle financeiro
- Não contém conteúdo de sexo, violência ou linguagem ofensiva
- O conteúdo é apenas funcional (gráficos, texto informativo)
- Não há imagens, vídeos ou áudios com conteúdo classificado

---

### **2. Partilha de Conteúdos dos Utilizadores**

**Pergunta:**
```
A aplicação permite, de origem, a interação ou troca de conteúdo 
entre utilizadores através de comunicação por voz, texto ou partilha 
de imagens ou áudio?
```

**Resposta para FinFlow:**
```
❌ NÃO
```

**Motivo:**
- O FinFlow não tem chat entre usuários
- Não permite comunicação entre usuários
- Não tem partilha de imagens/áudio entre usuários
- Os dados são apenas do próprio usuário

**Nota:** Mesmo que tenha WhatsApp/Email para suporte, isso não conta como "interação entre utilizadores" no app.

---

### **3. Conteúdo Online**

**Pergunta:**
```
A aplicação acede a conteúdos online ou fornece acesso a conteúdos online?
```

**Resposta para FinFlow:**
```
✅ SIM
```

**Motivo:**
- O app acessa a API (backend) para buscar e salvar dados
- Conecta-se à internet para sincronizar informações
- Pode ter links externos (política de privacidade, suporte)

**Após selecionar SIM, pode aparecer perguntas adicionais:**

#### **3.1 Que tipo de conteúdo online?**
- ✅ Apenas dados do usuário (API backend)
- ✅ Informações financeiras pessoais
- ❌ Conteúdo gerado por usuários de terceiros (não se aplica)
- ❌ Redes sociais (não se aplica)

#### **3.2 O conteúdo é filtrado/moderado?**
- O conteúdo é apenas dados do próprio usuário
- Não há conteúdo de terceiros para moderar

---

### **4. Promoção ou Venda de Produtos ou Atividades com Restrições de Idade**

**Pergunta:**
```
A aplicação promove ou vende produtos ou atividades com restrições 
de idade (por exemplo, álcool, tabaco, jogos de azar)?
```

**Resposta para FinFlow:**
```
❌ NÃO
```

**Motivo:**
- O FinFlow é um app de controle financeiro
- Não vende produtos
- Não promove álcool, tabaco, jogos de azar
- É apenas uma ferramenta de gestão financeira

---

### **5. Diversos**

**Pergunta:**
```
A aplicação tem outras características que possam necessitar de 
classificação?
```

**Resposta para FinFlow:**
```
❌ NÃO
```

**Motivo:**
- É um app simples de controle financeiro
- Não tem recursos adicionais que necessitem classificação

---

## ✅ Resumo das Respostas

| Pergunta | Resposta | Motivo |
|----------|----------|--------|
| **Aplicação transferida** | ❌ NÃO | Sem conteúdo classificado no código |
| **Partilha de Conteúdos dos Utilizadores** | ❌ NÃO | Sem comunicação entre usuários |
| **Conteúdo Online** | ✅ SIM | Acessa API para dados |
| **Promoção/Venda de Produtos Restritos** | ❌ NÃO | Não vende produtos |
| **Diversos** | ❌ NÃO | Sem outras características |

---

## 📝 Passo a Passo

1. **Selecione "NÃO"** para "Aplicação transferida"
2. **Selecione "NÃO"** para "Partilha de Conteúdos dos Utilizadores"
3. **Selecione "SIM"** para "Conteúdo Online"
   - Se aparecer perguntas adicionais, indique que é apenas dados do usuário
4. **Selecione "NÃO"** para "Promoção ou Venda de Produtos com Restrições"
5. **Selecione "NÃO"** para "Diversos" (se aparecer)
6. **Clique em "Salvar"** ou **"Avançar"**

---

## 🎯 Resultado Esperado

Após preencher corretamente, você deve ver:

**Classificação:**
- ✅ **Todos os Outros Tipos de Aplicações**
- ✅ Classificação adequada para todas as idades
- ✅ Sem restrições de conteúdo

## ⚠️ Importante

- **Seja honesto nas respostas** - Responda com base no que o app realmente faz
- **FinFlow é um app simples** - Não precisa de classificação específica
- **Se tiver dúvidas** - Escolha a opção mais conservadora (mais restritiva)
- **Pode ajustar depois** - Se precisar, pode alterar as respostas futuramente

---

## 💡 Dicas

1. **Lembre-se:** FinFlow é apenas uma ferramenta de controle financeiro
2. **Sem interação social:** Não tem chat, comentários ou comunicação entre usuários
3. **Dados pessoais:** O conteúdo online é apenas dados do próprio usuário
4. **Simples e seguro:** É um app seguro para todas as idades
