## 🔒 6. Segurança dos Dados (Data Safety)

**O app coleta ou compartilha algum dos tipos de dados do usuário obrigatórios?**  
**Resposta:** Sim  

### Dados declarados

| Tipo | Coletado | Finalidade | Compartilhado |
|------|----------|------------|---------------|
| **Dados financeiros** (receitas, despesas, contas, saldos) | Sim | Funcionalidade do app | Não |
| **Dados de conta** (e-mail, nome) | Sim | Autenticação | Não |
| **Dados de contato** (telefone, se informado) | Sim (opcional) | Notificações WhatsApp | Não |

### Declarações de segurança

- **Criptografia em trânsito:** Sim (HTTPS)  
- **Criptografia em repouso:** Sim  
- **Compartilhamento com terceiros:** Não  
- **Usuário pode solicitar exclusão de dados:** Sim  

### Texto sugerido para declarações

**Dados financeiros:**  
O Claricash coleta informações financeiras (receitas, despesas, contas) que o usuário insere no aplicativo. Esses dados são usados exclusivamente para fornecer a funcionalidade de gestão financeira pessoal. Os dados não são compartilhados com terceiros e são armazenados de forma segura e criptografada.

**Dados de conta:**  
O Claricash coleta informações de conta (e-mail, nome, telefone opcional) para autenticação e comunicação. Esses dados são usados apenas para permitir o acesso ao app e enviar notificações (se configurado pelo usuário). Os dados não são compartilhados com terceiros.
