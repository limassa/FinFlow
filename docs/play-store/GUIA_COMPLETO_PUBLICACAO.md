## 📦 Upload do AAB

### **1. Gerar AAB:**

**Comando:**
```bash
cd mobile
eas build --platform android --profile production
```

**Nota:** O EAS Build incrementa automaticamente o `versionCode`.

### **2. Download do AAB:**

Após o build, você receberá um link para download. Exemplo:
```
https://expo.dev/artifacts/eas/ka5wBTjDQpy9jc6FUivfDf.tar.gz
```

### **3. Extrair o AAB:**

1. Baixe o arquivo `.tar.gz`
2. Extraia o arquivo
3. Encontre o arquivo `.aab` dentro

### **4. Upload no Play Console:**

1. Vá em **"Testar e Lançar"** → **"Criar versão de teste fechado"** (ou **"Produção"**)
2. Clique em **"Fazer upload"** ou arraste o arquivo `.aab`
3. Aguarde o processamento

### **5. Verificar Erros:**

**Erro comum:** "O código de versão X já foi usado"

**Solução:**
1. Verifique o último `versionCode` usado no Play Console
2. Incremente o `versionCode` no `mobile/android/app/build.gradle`
3. Gere um novo AAB

**Exemplo:**
```gradle
versionCode 16  // Incrementar conforme necessário
```

### **6. Preencher Notas da Versão:**

Veja a seção [Store Listing](#store-listing-detalhes-da-loja) para as notas da versão.

## ⚠️ Problemas Comuns e Soluções

### **1. "O código de versão X já foi usado"**

**Problema:** O Play Console rejeita o AAB porque o `versionCode` já foi usado.

**Solução:**
1. Verifique o último `versionCode` usado no Play Console
2. Abra `mobile/android/app/build.gradle`
3. Incremente o `versionCode`:
   ```gradle
   versionCode 16  // Use um número maior que o último usado
   ```
4. Gere um novo AAB
5. Faça upload novamente

**Documento detalhado:** `docs/play-store/SOLUCAO_VERSION_CODE.md`

---

### **2. "O nível desejado da API do app é 34. No entanto, esse nível precisa ser de pelo menos 35"**

**Problema:** O Play Store requer `targetSdkVersion` 35.

**Solução:**
1. Verifique `mobile/android/app/build.gradle`
2. Certifique-se de que `targetSdkVersion` está como 35:
   ```gradle
   targetSdkVersion 35
   ```
3. Gere um novo AAB

**Documento detalhado:** `docs/play-store/SOLUCAO_API_35.md`

---

### **3. "Não há um arquivo de desofuscação associado"**

**Problema:** Aviso sobre arquivo de desofuscação (ProGuard/R8).

**Solução:**
- Este é apenas um **aviso**, não um erro
- O ProGuard já está habilitado
- O Play Console pode gerar o arquivo automaticamente
- Você pode prosseguir com a publicação

---
