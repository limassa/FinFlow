# Nomes do sistema (web + app)

Sugestões de nome para o sistema como um todo (site e aplicativo) e checklist para verificar disponibilidade.

---

## Nome único para web e app

Usar **um nome só** para o site e para o app deixa a marca mais consistente:

- Usuário entende que é o mesmo produto (“acesse no site ou baixe o app”).
- “GranaAPP” soa mais como nome só do app; um nome como **ContaCerta** funciona bem para os dois.

**Sugestão:** usar **ContaCerta** (ou **Conta Certa**) como nome do sistema. Se quiser, dá para usar “ContaCerta” no produto e “ContaCerta – GranaAPP” só como subtítulo do app, mas não é obrigatório.

---

## O que já existe (ContaCerta / Conta Certa)

- **Google Play:** há apps com “Conta Certa” no nome, por exemplo:
  - “Conta Certa: Divisão de Gastos” (dividir conta em bares/restaurantes)
  - “Conta Certa Contabilidade” (contabilidade)
- A expressão “Conta Certa” já é usada por outros apps, mas **“ContaCerta”** (uma palavra, produto de finanças pessoais) pode ainda ser utilizável como marca e nome de app. Vale pesquisar nas lojas e, se for o caso, consultar um advogado de marcas.

---

## Checklist de disponibilidade

Antes de definir o nome, confira:

| O quê | Onde verificar |
|-------|----------------|
| **Domínio .com.br** | [Registro.br](https://registro.br) → Pesquisar domínio (ex.: `contacerta.com.br`) |
| **Domínio .com** | GoDaddy, Hostinger, Registro.br ou outro registrador → pesquisa de domínio |
| **Google Play** | Pesquisar “ContaCerta” e “Conta Certa” na Play Store |
| **App Store (Apple)** | Pesquisar o mesmo na App Store |
| **Marca (INPI)** | [Busca no INPI](https://www.gov.br/inpi/pt-br) → verificar se já existe marca “ContaCerta” / “Conta Certa” nas classes de software/app/serviços financeiros |

## Teste Interno na Play Store – dá problema?

**Não.** Estar na etapa de **Teste Interno** (Internal Testing) não gera problema para o nome nem para a publicação.

- **Quem vê o app:** só os testadores que você adicionou (lista de e-mails). O app **não aparece** na busca pública da Play Store.
- **Nome do app:** o nome que você colocou na ficha do app no Play Console é só para essa versão. Você pode **alterar o nome** (e título na loja) a qualquer momento, inclusive antes de enviar para Produção.
- **Sequência normal:** Teste Interno → (opcional) Teste Fechado → Produção. Começar pelo Teste Interno é o fluxo esperado.

Ou seja: pode seguir no Teste Interno tranquilo. Quando definir o nome final (ex.: ContaCerta), basta ajustar **Nome do app** e **Título** na página da listagem do app no Play Console antes de solicitar o acesso de produção ou publicar em Produção.

---

## Resumo

1. Definir um nome único para web e app (ex.: ContaCerta).
2. Verificar domínios (.com.br e .com) e lojas (Play Store, App Store) e, se quiser, INPI.
3. Estar em Teste Interno na Play Store não atrapalha; o nome pode ser alterado antes de ir para Produção.
