# 📋 Como Preencher Classificações de Conteúdo - FinFlow

Guia completo para preencher TODAS as perguntas do questionário de Classificações de Conteúdo do Google Play Console.

---

## 🎯 Respostas para o App FinFlow

### **1. Aplicação transferida** ✅ CONCLUÍDA

**Pergunta:**
```
A aplicação contém quaisquer conteúdos com classificação relevante 
(por exemplo, sexo, violência, linguagem) transferidos como parte 
do pacote de aplicações (código, ativos)?
```

**Resposta para FinFlow:**
```
❌ NÃO
```

**Motivo:**
- O FinFlow é um app de controle financeiro
- Não contém conteúdo de sexo, violência ou linguagem ofensiva
- O conteúdo é apenas funcional (gráficos, texto informativo)
- Não há imagens, vídeos ou áudios com conteúdo classificado

---

### **2. Partilha de Conteúdos dos Utilizadores** ✅ CONCLUÍDA

**Pergunta:**
```
A aplicação permite, de origem, a interação ou troca de conteúdo 
entre utilizadores através de comunicação por voz, texto ou partilha 
de imagens ou áudio?
```

**Resposta para FinFlow:**
```
❌ NÃO
```

**O que essa pergunta quer saber:**
A Google quer saber se seu app permite que **usuários conversem entre si** dentro do app, como:
- Chat entre usuários (WhatsApp, Messenger, Discord)
- Comentários públicos entre usuários (Instagram, Facebook)
- Fóruns ou comunidades onde usuários interagem
- Compartilhamento de imagens/vídeos entre usuários (redes sociais)
- Comunicação por voz entre usuários (chamadas, videoconferência)

**Por que a resposta é NÃO para FinFlow:**

✅ **O FinFlow NÃO permite:**
- Chat entre usuários
- Comunicação entre usuários no app
- Compartilhamento de imagens/áudio entre usuários
- Interação social entre usuários
- Fóruns ou comentários públicos

✅ **O FinFlow permite apenas:**
- Usuário gerencia seus próprios dados financeiros
- Usuário acessa suas próprias informações
- **NÃO há comunicação entre usuários**

**Nota importante:**
- Mesmo que tenha WhatsApp/Email para **suporte ao cliente** (você atendendo usuários), isso **NÃO conta** como "interação entre utilizadores"
- "Interação entre utilizadores" significa **usuários conversando entre si**, não usuário falando com suporte
- O FinFlow é um app **individual** - cada usuário gerencia apenas seus próprios dados
- Não há funcionalidade social ou colaborativa no app

**Exemplos de apps que responderiam SIM:**
- WhatsApp (usuários conversam entre si)
- Instagram (usuários comentam posts uns dos outros)
- Discord (usuários conversam em servidores)
- Facebook (usuários interagem em posts)

**Exemplos de apps que responderiam NÃO (como FinFlow):**
- Calculadora (apenas o usuário usa)
- App bancário (apenas o usuário acessa suas contas)
- App de notas (apenas o usuário gerencia suas notas)
- FinFlow (apenas o usuário gerencia suas finanças)

**Conclusão:** A resposta é **NÃO** ✅

---

### **3. Conteúdo Online** ✅ CONCLUÍDA

**Pergunta:**
```
A aplicação destaca ou incentiva conteúdos que não fazem parte da 
transferência inicial da aplicação, mas que podem ser acedidos a 
partir da aplicação? Exemplos deste tipo de conteúdos são filmes na 
aplicação Netflix, listas de produtos na aplicação Amazon Shopping, 
músicas na aplicação Spotify, conteúdo gerado por IA ou artigos de 
notícias na aplicação New York Times.
```

**Resposta para FinFlow:**
```
❌ NÃO
```

**O que essa pergunta quer saber:**
A Google quer saber se seu app mostra **conteúdo externo** ou de **terceiros**, como:
- Filmes/vídeos de streaming (Netflix, YouTube)
- Produtos de lojas online (Amazon, Mercado Livre)
- Músicas de streaming (Spotify, Deezer)
- Artigos de notícias (jornal online)
- Conteúdo gerado por IA
- Conteúdo criado por outros usuários

**Por que a resposta é NÃO para FinFlow:**

✅ **O FinFlow NÃO:**
- Não mostra filmes ou vídeos
- Não vende produtos de lojas
- Não tem conteúdo de streaming
- Não tem artigos de notícias
- Não tem conteúdo gerado por IA
- Não mostra conteúdo de terceiros
- Não incentiva acesso a conteúdo externo

✅ **O FinFlow apenas:**
- Acessa API backend para dados do próprio usuário
- Mostra dados financeiros do próprio usuário
- Conecta-se à internet apenas para sincronizar dados pessoais
- Links externos são apenas para política de privacidade (opcional)

**Exemplos de apps que responderiam SIM:**
- Netflix (mostra filmes de terceiros)
- Amazon Shopping (mostra produtos de lojas)
- Spotify (mostra músicas de artistas)
- Instagram (mostra posts de outros usuários)
- New York Times (mostra artigos de notícias)

**Exemplos de apps que responderiam NÃO (como FinFlow):**
- App bancário (apenas dados do próprio usuário)
- Calculadora (não acessa conteúdo externo)
- FinFlow (apenas dados financeiros do próprio usuário)

**Nota importante:**
- Acessar API backend para dados do usuário **NÃO** é considerado "conteúdo online" nesta pergunta
- "Conteúdo online" aqui significa conteúdo de **terceiros** ou **externo** que não é do próprio usuário
- Se o app apenas sincroniza dados do próprio usuário, a resposta é **NÃO**

**Conclusão:** A resposta é **NÃO** ✅
