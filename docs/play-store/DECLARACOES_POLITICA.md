# 📋 Declarações de Política - Play Store

Guia para preencher as 4 declarações pendentes no Play Console.

---

## 🎯 Declarações que Precisam de Atenção

1. ✅ **ID de publicidade**
2. ✅ **Apps governamentais**
3. ✅ **Recursos financeiros**
4. ✅ **Apps de saúde**

---

## 1️⃣ ID de Publicidade

### **Pergunta:**
**"O app usa um ID de publicidade?"**

### **Resposta para FinFlow:**
❌ **NÃO**

### **Justificativa:**
- O FinFlow **não tem anúncios**
- Não usa Google AdMob
- Não usa outros serviços de publicidade
- Não coleta ou usa ID de publicidade

### **Como Preencher:**
1. Selecione: **"Não, o app não usa ID de publicidade"**
2. Ou: **"Não usa ID de publicidade"**

### **⚠️ Importante:**
- Esta declaração é **obrigatória** para apps Android 13+
- Deve ser preenchida antes de enviar versões

---

## 2️⃣ Apps Governamentais

### **Pergunta:**
**"O app é para uso de um governo de qualquer tipo?"**

### **Resposta para FinFlow:**
❌ **NÃO**

### **Justificativa:**
- FinFlow é um app **privado/comercial**
- Desenvolvido por **Liz Softwares** (empresa privada)
- Não é desenvolvido ou gerenciado por governo
- Não é para uso governamental

### **Como Preencher:**
1. Selecione: **"Não, o app não é governamental"**
2. Ou: **"Não é um app governamental"**

### **⚠️ Importante:**
- Esta declaração é **obrigatória** para todos os apps
- Deve ser preenchida para lançar atualizações

---

## 3️⃣ Recursos Financeiros

### **Pergunta:**
**"O app oferece recursos financeiros?"**

### **Resposta para FinFlow:**
✅ **SIM** (mas como ferramenta de gestão, não serviço financeiro)

### **Detalhes:**

#### **Tipo de Recurso:**
- ✅ **Ferramenta de gestão financeira pessoal**
- Similar a uma planilha de controle financeiro

#### **O que o app NÃO oferece:**
- ❌ **Serviços de pagamento**
- ❌ **Empréstimos ou crédito**
- ❌ **Processamento de transações financeiras**
- ❌ **Serviços bancários**
- ❌ **Investimentos ou corretagem**
- ❌ **Carteiras digitais**
- ❌ **Transferências de dinheiro**

#### **O que o app oferece:**
- ✅ **Organização de receitas e despesas**
- ✅ **Controle de contas bancárias**
- ✅ **Gráficos e relatórios**
- ✅ **Lembretes de vencimentos**
- ✅ **Calculadoras financeiras**

### **Como Preencher:**

1. **"O app oferece recursos financeiros?"**
   - Resposta: ✅ **SIM**

2. **"Tipo de recurso:"**
   - Selecione: **"Ferramenta de gestão financeira pessoal"**
   - Ou: **"Organização financeira"**

3. **"O app processa pagamentos?"**
   - Resposta: ❌ **NÃO**

4. **"O app oferece empréstimos ou crédito?"**
   - Resposta: ❌ **NÃO**

5. **"O app requer licença bancária?"**
   - Resposta: ❌ **NÃO**

### **Declaração Sugerida:**
```
O FinFlow é uma ferramenta de gestão financeira pessoal que permite 
ao usuário organizar e acompanhar suas receitas e despesas. É similar 
a uma planilha de controle financeiro.

O app NÃO oferece:
- Serviços de pagamento
- Empréstimos ou crédito
- Processamento de transações financeiras
- Serviços bancários

O app apenas ajuda o usuário a organizar suas próprias informações 
financeiras inseridas manualmente.
```

### **⚠️ Importante:**
- Esta declaração é **obrigatória** para apps com recursos financeiros
- Deixe claro que é **ferramenta de gestão**, não **serviço financeiro**
- Não requer licença bancária

### **Como Preencher:**
1. Selecione: **"Não, o app não usa recursos de saúde"**
2. Ou: **"Não é um app de saúde"**

### **⚠️ Importante:**
- Esta declaração é **obrigatória** para todos os apps
- Deve ser preenchida para ajudar o Google a entender os requisitos
